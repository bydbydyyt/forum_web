# 论坛与私聊系统

这是一个基于Django开发的现代化论坛和私聊系统。

## 主要功能

- 论坛功能
  - 分区发帖
  - 支持文字、图片、视频内容
  - 点赞和收藏功能
  - 热度排行榜
  - 违禁词过滤
  
- 私聊功能
  - 好友系统
  - 实时聊天
  - 文件传输
  - 图片视频分享

- 用户系统
  - 个人主页
  - 自定义背景图片
  - 个人简介
  - 好友代码系统
  - 收藏夹管理

## 背景自定义功能

### 🎨 个性化背景设置
- **拖拽上传**：支持拖拽图片到上传区域
- **图片裁剪**：自动弹出裁剪界面，支持多种宽高比
- **尺寸选择**：支持4种不同尺寸（宽屏、方形、竖屏、超宽）
- **预设背景**：提供6种精美渐变背景
- **实时预览**：上传前可预览效果
- **格式支持**：JPG、PNG、GIF格式
- **大小限制**：最大5MB，支持多种尺寸选择

### 🎯 使用方法

1. **上传自定义背景：**
   - 进入个人设置页面
   - 点击"背景设置"标签
   - 选择背景尺寸（宽屏、方形、竖屏、超宽）
   - 拖拽图片或点击选择文件
   - 在裁剪界面调整图片（自动适配所选尺寸）
   - 保存设置

2. **使用预设背景：**
   - 进入个人设置页面
   - 点击"背景设置"标签
   - 选择背景尺寸
   - 选择喜欢的渐变背景
   - 保存设置

### 🌈 预设背景
- 蓝紫渐变：优雅的蓝紫色调
- 粉红渐变：温暖的粉红色调
- 青蓝渐变：清新的青蓝色调
- 绿青渐变：自然的绿青色调
- 粉黄渐变：活力的粉黄色调
- 青粉渐变：柔和的青粉色调

### 📐 背景尺寸
- **宽屏 (1200x400)**：适合传统横幅显示
- **方形 (800x600)**：适合正方形布局
- **竖屏 (600x800)**：适合垂直显示
- **超宽 (1000x300)**：适合超宽屏显示

## 技术栈

- 后端：Django 5.0
- 前端：Bootstrap 5 + Cropper.js
- 实时通信：Django Channels
- 数据库：SQLite（开发）/ PostgreSQL（生产）
- 文件存储：本地存储
- 图片处理：Pillow

## 安装说明

1. 创建虚拟环境：
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

2. 安装依赖：
```bash
pip install -r requirements.txt
```

3. 数据库迁移：
```bash
python manage.py migrate
```

4. 创建超级用户：
```bash
python manage.py createsuperuser
```

5. 运行开发服务器（使用 Daphne）：
```bash
daphne -b 127.0.0.1 -p 8000 forum_web.asgi:application
```
